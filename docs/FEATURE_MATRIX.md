# 完整输入法功能矩阵

本文件是项目功能范围与验收基线。目标是吸收百度输入法、搜狗输入法等成熟产品的通用能力，并加入本项目的逐字输入特色。功能未经过实现与测试前，不得标记为已完成。

## 设计原则

- 基础输入优先：断网时仍可完成拼音、英文、手写（离线模型具备时）、编辑和常用符号输入。
- 联网功能可关闭：云候选、热词、在线搜索、在线翻译、表情资源下载均需独立开关。
- 权限按需申请：麦克风、相机、照片等仅在用户主动使用相应功能时申请。
- 明示数据流向：输入内容默认不上传；云输入、翻译、搜索等上传前应说明用途并允许关闭。
- 能力如实展示：离线语音、语言翻译、方言识别等按设备、引擎和模型实际能力标记，不以空按钮冒充功能。
- 不复制竞品专有代码、商标、皮肤或受版权保护的表情资源；采用自研界面和合法授权/开放资源。

## 语言范围

大众语言优先：简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、意大利语、阿拉伯语。其他语言按实际用户需求和引擎支持情况扩展，不为追求数量牺牲准确率。

语音识别、键盘输入和机器翻译是不同能力，必须分别列出每种语言的支持状态。不能因为支持某语言键盘，就宣称支持该语言离线语音或翻译。

## 分阶段验收

### P0：可日常打字
- 输入法服务稳定启动并能在第三方输入框上屏。
- 中文全键拼音、基础候选、英文键盘、九宫格、数字/标点。
- 退格、长按清空、光标编辑、剪贴板和快捷短语。
- Emoji、颜文字面板。
- 逐字输入状态机：新剪贴板只暂停，不覆盖当前任务；继续从原索引恢复。

### P1：智能与多语言
- 接入经过许可审查的拼音/词库引擎，支持整句候选和词频学习。
- 双拼、手写、常用多语言键盘。
- 在线与设备端语音识别能力检测、自动切换。
- 常用语言翻译并直接上屏。
- 云候选、热词更新均可关闭。

### P2：扩展体验
- OCR、在线搜索、表情包搜索、AI表达、主题商店、云同步、游戏键盘。
- 每项功能独立验收权限、网络行为、失败提示和性能。

## 验收规则

- GitHub Actions 构建成功只代表编译通过，不代表功能验收通过。
- 每个功能必须有实现记录、测试步骤和测试结果。
- 真机测试至少覆盖 Android 版本、微信输入框、原子笔记输入框和普通文本框。
- 网络关闭、权限拒绝、模型未下载、服务不可用时，必须有合理降级，不得崩溃或假装成功。
